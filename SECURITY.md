## Supported versions

| Version | Supported |
| --- | --- |
| `main` and the current `latest` image | Yes |
| The current `edge` image (release candidate) | Best effort |
| Older version tags and unmaintained branches | No |

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability.

Use GitHub's **Report a vulnerability** option in the repository's
[Security tab](https://github.com/Luprintech/openclaw-nas-docker/security/advisories/new).
Include a clear impact description, reproduction steps, affected versions,
and a safe proof of concept. Do not include tokens, certificates, private IP
addresses, or other credentials.

We will acknowledge reports, assess the impact, and coordinate a fix before
public disclosure when appropriate.

Vulnerabilities in OpenClaw itself should also be reported to the
[OpenClaw project](https://github.com/openclaw/openclaw).
