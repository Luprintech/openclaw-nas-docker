# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` and the latest published NAS image | Yes |
| Older images and unmaintained branches | No |

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability.

Use GitHub's **Report a vulnerability** option in the repository's Security
tab. Include a clear impact description, reproduction steps, affected versions,
and a safe proof of concept. Do not include tokens, certificates, private IP
addresses, or other credentials.

We will acknowledge reports, assess the impact, and coordinate a fix before
public disclosure when appropriate.
