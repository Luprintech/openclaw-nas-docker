# Code of Conduct

## Our pledge

We want this project to be a welcoming and constructive place for everyone.
Participation is expected to be respectful, professional, and focused on
making OpenClaw on NAS safer and easier to run.

## Expected behavior

- Be respectful of different experience levels and technical backgrounds.
- Give feedback about code and ideas, not people.
- Explain security and operational risks clearly and without sharing secrets.
- Assume good intent, ask for clarification, and help others learn.

## Unacceptable behavior

- Harassment, discrimination, intimidation, or personal attacks.
- Publishing another person's private information, credentials, logs, or
  network details without permission.
- Deliberately unsafe instructions, malicious code, or abusive behavior.

## Enforcement

The repository owner may edit, reject, or remove contributions and may block
participants who violate this code of conduct. Report concerns privately using
the contact options on the repository owner's GitHub profile; do not publish
sensitive reports in an issue or pull request.
