## Versiones con soporte

| Versión | Soporte |
| --- | --- |
| `main` y la imagen `latest` actual | Sí |
| La imagen `edge` actual (candidata) | En la medida de lo posible |
| Etiquetas de versiones anteriores y ramas sin mantenimiento | No |

## Cómo informar de una vulnerabilidad

**No** abras una issue pública si sospechas que hay una vulnerabilidad.

Usa la opción **Report a vulnerability** de la
[pestaña Security](https://github.com/Luprintech/openclaw-nas-docker/security/advisories/new)
del repositorio. Incluye una descripción clara del impacto, los pasos para
reproducirla, las versiones afectadas y una prueba de concepto segura. No
incluyas tokens, certificados, direcciones IP privadas ni otras credenciales.

Confirmaremos la recepción del aviso, evaluaremos el impacto y coordinaremos
una corrección antes de hacerlo público cuando corresponda.

Las vulnerabilidades del propio OpenClaw también deben comunicarse al
[proyecto OpenClaw](https://github.com/openclaw/openclaw).
