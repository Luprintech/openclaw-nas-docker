# Código de conducta

[English](CODE_OF_CONDUCT.md) | **Español**

## Nuestro compromiso

Queremos que este proyecto sea un lugar acogedor y constructivo para todo el
mundo. Esperamos una participación respetuosa, profesional y centrada en hacer
que OpenClaw en NAS sea más seguro y más fácil de usar.

## Comportamiento esperado

- Respeta los distintos niveles de experiencia y conocimientos técnicos.
- Comenta el código y las ideas, no a las personas.
- Explica los riesgos de seguridad y de operación con claridad y sin compartir
  secretos.
- Presupón buena intención, pide aclaraciones y ayuda a los demás a aprender.

## Comportamiento inaceptable

- Acoso, discriminación, intimidación o ataques personales.
- Publicar sin permiso información privada, credenciales, logs o datos de red
  de otra persona.
- Instrucciones deliberadamente inseguras, código malicioso o comportamiento
  abusivo.

## Aplicación

La propietaria del repositorio puede editar, rechazar o eliminar
contribuciones, y bloquear a quien incumpla este código de conducta.

Comunica cualquier problema en privado mediante el
[formulario de aviso privado](https://github.com/Luprintech/openclaw-nas-docker/security/advisories/new)
del repositorio (pestaña Security → **Report a vulnerability**). No publiques
avisos delicados en una issue ni en un pull request.
